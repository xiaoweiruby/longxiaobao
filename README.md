# 龙小宝IP形象设计网站

这是一个展示"龙小宝"IP形象设计的静态网站。

## 部署说明

### Vercel部署

1. 在Vercel上创建新项目
2. 连接到你的代码仓库或直接上传这些文件
3. 部署时会自动识别项目为静态网站
4. 部署完成后，你的网站将可以通过Vercel分配的域名访问

### 项目结构

- `longxiaobao.html`: 主要HTML文件
- `public/`: 包含所有静态资源（图片、音频等）
  - `主视图/`: 主角色设计图
  - `变装图/`: 不同场景的变装图
  - `周边图/`: 周边产品设计
  - `海报图/`: 宣传海报
  - `表情包/`: 表情包设计
- `vercel.json`: Vercel配置文件

## 注意事项

- 所有图片和媒体文件已配置为使用`/public/`路径前缀
- 如需修改图片，请确保放置在对应的文件夹并使用相同的文件名
