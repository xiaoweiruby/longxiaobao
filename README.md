# 龙小宝IP形象设计网站

这是一个展示"龙小宝"IP形象设计的静态网站。

## 部署说明

### Vercel部署

1. 在Vercel上创建新项目
2. 连接到你的代码仓库或直接上传这些文件
3. 部署时会自动识别项目为静态网站
4. 部署完成后，你的网站将可以通过Vercel分配的域名访问

### 项目结构

- `index.html`: 主要HTML文件
- `public/`: 包含所有静态资源（图片、音频等）
  - `主视图/`: 主角色设计图
  - `变装图/`: 不同场景的变装图
  - `周边图/`: 周边产品设计
  - `海报图/`: 宣传海报
  - `表情包/`: 表情包设计
- `vercel.json`: Vercel配置文件

## 注意事项

- 所有图片和媒体文件使用相对路径引用，如 `public/主视图/文件名.png`
- 这种路径配置确保了在本地开发和Vercel部署环境下都能正确加载资源
